# Cuckoo Recipes

A Recipe is a ready-made Job file for [Cuckoo](https://cuckoo.jonathan.pt): a command, a schedule
and a few settings you can copy into your own Cuckoo and adjust.

Browse them at https://cuckoo.jonathan.pt/recipes.

Needs Cuckoo 0.2.0 or later.

Each Recipe is one file in [`recipes/`](recipes/). Want to add one? Read
[CONTRIBUTING.md](CONTRIBUTING.md).
